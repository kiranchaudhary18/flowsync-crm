## Overview

FlowSync CRM is a premium SaaS landing page designed to present a modern Customer Relationship Management platform with an AI-first user experience.

The project focuses on delivering clean UI, smooth animations, reusable components, responsive layouts and production-ready architecture while following modern frontend development practices.

## Getting Started

Clone the repository

```bash
git clone https://github.com/kiranchaudhary18/flowsync-crm.git
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Create production build

```bash
npm run build
```

Start production server

```bash
npm start
```
